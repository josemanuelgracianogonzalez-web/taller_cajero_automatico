# Sistema de Cajero Automático
 
Proyecto desarrollado en JavaScript que simula el funcionamiento de un cajero
automático desde consola.
 
## Funcionalidades
- Inicio de sesión con verificación de usuario y contraseña
- Consulta de saldo
- Retiro de dinero
- Depósito de dinero
- Historial de movimientos
- Salida del sistema
 
## Tecnologías
- JavaScript
- Ejecución desde consola (Visual Studio Code)
